## Format-Empfehlungen

- **Referenzen (Kacheln):** Querformat, 4:3, mindestens 1200×900 px, JPEG unter 200 KB
- **Team (Porträts):** Quadratisch, mindestens 400×400 px, Gesicht mittig
- **Alle Bilder:** JPEG mit Qualität 80–85%, ohne EXIF-Daten (Datenschutz)

Zum Optimieren: [squoosh.app](https://squoosh.app) oder ImageOptim.
