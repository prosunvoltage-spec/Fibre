# Bilder für die KYL-Website

Lege deine Fotos einfach mit dem genannten Dateinamen in diesen Ordner. Die Seite
erkennt sie automatisch und ersetzt den Farbverlauf-Platzhalter. Fehlt ein Foto,
bleibt der Platzhalter sichtbar – es bricht nichts.

## Erwartete Dateien

| Dateiname | Wo | Format |
|---|---|---|
| `hero.jpg` | Hero-Hintergrund | Querformat, mind. 2000×1200 px |
| `projekt-terrassendach.jpg` | Projekte, große Kachel | Querformat 4:3, mind. 1600×1200 px |
| `projekt-wege-flaechen.jpg` | Projekte | Querformat 4:3, mind. 1200×900 px |
| `projekt-fensterreinigung.jpg` | Projekte | Querformat 4:3, mind. 1200×900 px |
| `projekt-pv-reinigung.jpg` | Projekte | Querformat 4:3, mind. 1200×900 px |
| `projekt-waermepumpe.jpg` | Projekte | Querformat 4:3, mind. 1200×900 px |
| `projekt-glasreinigung.jpg` | Projekte | Querformat 4:3, mind. 1200×900 px |
| `projekt-pv-anlage.jpg` | Projekte | Querformat 4:3, mind. 1200×900 px |
| `team.jpg` | Über uns | Quadratisch, mind. 1200×1200 px |

## Empfehlungen

- JPEG mit Qualität 80–85 %, unter 250 KB pro Bild (Hero bis 400 KB)
- EXIF-Daten entfernen (Datenschutz, kleinere Dateien)
- Optimieren mit [squoosh.app](https://squoosh.app) oder ImageOptim

## Alt-Texte

Die Alt-Texte stehen direkt in `index.html` neben dem jeweiligen `<img>`. Nach dem
Einsetzen echter Fotos dort prüfen, ob die Beschreibung noch zum Bild passt.
